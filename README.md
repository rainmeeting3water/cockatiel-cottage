# 玄鳳小日子 v0.3.1

陪一隻玄鳳換水、吃飯、散步，也學會尊重牠想休息的時候。繁體中文、手機與電腦皆可操作。

**v0.3.1 原始碼分享版。** 專案位於 [rainmeeting3water/cockatiel-cottage](https://github.com/rainmeeting3water/cockatiel-cottage)。可按 **Code → Download ZIP** 下載並解壓縮，再開啟 `standalone.html` 試玩。GitHub Pages 尚未啟用，目前沒有公開試玩網站。

## 先玩玩看

下載完整專案後，開啟專案裡的 `standalone.html`。若拿到另外交付的單檔版，也可直接開啟 `玄鳳小日子-v0.3.1-本機體驗版.html`。角色與動畫已包含，不用安裝套件。聽歌需要網路，請按「到 YouTube 聽原版」。直接開檔的儲存行為仍需一般瀏覽器確認。

已有 Node.js 時，也可在這個資料夾執行：

```powershell
node preview.cjs
```

開啟 `http://127.0.0.1:4173`；Ctrl+C 停止。只綁定本機，不上傳、不發布。另一台手機不能用這個網址直接連入。

## 這版可以做什麼

- **先看圖學照顧**：七張原創圖解、八張可展開照顧卡與 24 項食物圖片查詢。急症提醒一直看得到。羽色不決定個性，資料不足的食物先不餵。
- **陪鳥寶過日子**：換水、備餐、清理、陪玩、安全放風。三款原創寫實角色會走、理毛、唱歌與飛行；這是遊戲動畫，不能判斷真鳥健康。
- **安心離開**：門窗、吊扇、貓狗、危險物品先檢查，再確認回籠。當機、斷線或不確定，不直接當疏忽；離線不扣分。
- **私人照片牆與布置**：五種相框、PNG 成品預覽、獨立相簿備份；八種小物與三種房間色調。照片只存在自己的瀏覽器，沒有公開牆。
- **鳥寶創作室**：本機參考照 → 複製提示詞 → 自行選擇圖片工具 → 匯入 16 格動作圖 → 試走、試飛 → 本次套用。網站不呼叫 AI、不上傳照片；生成工具由使用者自行選擇，可能收費。重新整理後回到原本角色。
- **原作者聽歌連結**：The Kiffness × Ginger 官方音樂版，以及 Ginger 本人示範。沒有下載重製歌曲。file 網址的 YouTube 153 是來源識別問題，與後端無關。公開候選網站採外連收聽；嵌入需完成相關設定並實測。

## 紀錄和照片放在哪裡

照顧使用 localStorage v2，可讀舊 v1／v2；布置獨立 v1。遊戲備份含照顧與布置，寫入失敗會嘗試還原並明示結果。照片放 IndexedDB，最多 12 張，需另外按「備份照片」。相片限 JPG／PNG／靜態 WebP，10 MB、2400 萬畫素以下；會縮小並重新編碼，不保留原檔拍攝資訊。拒絕 SVG、動圖與遠端圖片網址。

創作室的照片與動作圖只在本次記憶體，不存相簿、不進遊戲備份；請自行保存動作圖。16 格檢查只確認尺寸、透明度與非空，不會認出照片中的鳥，也不能判斷動作是否正確，需人工逐格看。

清除瀏覽器資料、結束無痕視窗、更換裝置／瀏覽器／網址／連接埠，可能失去或看不到紀錄。更新會先驗證舊資料，不保證所有未來版本相容，不相容原檔不直接覆寫。重新開始故事保留相簿與布置；重置前會確認。

免登入、無分析追蹤、雲端資料庫或公開聊天，不蒐集生日、位置或聯絡方式。照片不要拍到人臉、姓名、地址。網站不送出私人紀錄；按外部來源／YouTube 連結後，適用各服務政策。

## 照顧資料

飲食、毒物與醫療摘要來源見 `content.js` 與頁面連結，查核 2026-11-08；YouTube 播放規則另查核 2026-11-09。AAV 與 VCA 飲食比例建議不同，本版不提供通用克數、配比或用藥劑量。部分 AAV 網頁取得受限，限制保留在審閱紀錄。

真鳥呼吸困難、嚴重虛弱、持續出血或可能中毒，應立即找鳥類獸醫；小朋友先找照顧的大人。遊戲數值、四階段故事與醫療代幣都是教學設定，不代表疾病機率、報價或預後。

仍需鳥類獸醫審閱：[VETERINARY-REVIEW.md](VETERINARY-REVIEW.md)。動畫來源見 [ASSETS.md](ASSETS.md)，歌曲與播放查證見 [MUSIC-SOURCES.md](MUSIC-SOURCES.md)。字體沿用先前查閱清冊後的本機 Noto Sans TC／系統備援，未下載、安裝或散布字型。

## 修改與封裝

沒有外部程式依賴。`app.js` 整合頁面；`core.js` 照顧；`motion.js` 動畫；`guides.js` 圖解；`creator.js` 本機創作；`gallery.js` 相簿；`decor.js` 布置；`backup.js` 組合備份。

```powershell
node --test tests/*.test.cjs
node tools/package.cjs
node tools/build-public.cjs
```

第一個跑本機測試。第二個更新單檔 `standalone.html` 與 `VERSION.json` 版本雜湊。第三個依固定白名單產生 `docs/` 與完整 `PUBLIC-FILES.json`，拒絕未知檔案或連結；不把相簿、備份、測試或教學文件放進網站。指令不安裝、不連網、不執行 Git、不發布。

實測與限制見 [TESTING.md](TESTING.md)。尚未做跨裝置同步、多鳥、公開相簿或網站內 AI 生圖；模擬手機不代表真實手機驗收。Git 與 Pages 公開操作仍需另外確認。
