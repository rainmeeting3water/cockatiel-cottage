# 把小屋帶回家

這份教學讓你下載、試玩，再做出自己的版本。完整檔案可從 [GitHub 專案](https://github.com/rainmeeting3water/cockatiel-cottage) 的 Code → Download ZIP 取得；解壓縮後操作，不要在 ZIP 裡直接修改。先找大人一起看；不用登入，也不用先付錢。

## 只想玩

公開網站尚未建立。發布後會在 README 最上方放「開始玩」連結。目前可開啟交付的 v0.3.1 本機體驗版 HTML；聽歌請按「到 YouTube 聽原版」。

## 想改成自己的小屋

1. 在 GitHub 專案按綠色 **Code → Download ZIP**，下載後解壓縮。不要在 ZIP 裡直接修改。
2. 先讀 README、TESTING、VETERINARY-REVIEW。先保留原版，另外複製一份來改。
3. 已有 Node.js 的電腦，可在專案資料夾執行 `node preview.cjs`，再開 `http://127.0.0.1:4173`。這只開本機預覽，Ctrl+C 停止。不需要 npm install。若沒裝 Node.js，先用單檔體驗版；請大人決定是否另外安裝工具。
4. 開 Codex 或你信任的程式助手，把下方提示詞貼給它，一次改一件事。不要貼帳號密碼或私人照片。
5. 完成後先測試。公開前確認照片、素材授權及網站會送出哪些資料。下載不會自動發布。

## 可以直接貼的修改提示詞

```text
請先讀這個專案的 README.md、TESTING.md、VETERINARY-REVIEW.md、PUBLIC-FILES.json。
我要修改「玄鳳小日子」，請保留繁體中文、手機與鍵盤操作、本機私人相簿、可匯出紀錄，以及公平的離開補確認。
先檢查檔案，說明你要改哪些檔案，再開始。不要安裝依賴、登入、公開照片、建立服務或發布網站。
這次只想改：【在這裡寫一件事，例如把小屋配色改成天空藍】。
原創角色與介面可以改；飲食、毒物、健康內容不能憑想像增加，需可靠獸醫來源與查核日期。
不要讓遊戲數值冒充真鳥診斷，不提供自行用藥劑量，不把羽色綁定個性。
完成後檢查手機寬度、鍵盤操作、舊存檔和重載。列出真正通過的檢查與尚未確認的地方。
```

## 版本靈感

- 家中有兩隻鳥：先規劃每隻獨立紀錄、相處距離與分開休息，不能直接假設一定合得來。
- 換一種鸚鵡：先換教材與專業來源，再改角色。不能把玄鳳食物資料直接當成所有鳥的通用規則。
- 班級觀察版：用假名字與練習紀錄，不收學生生日、位置、照片或成績。先讓老師檢查。
- 只想聽歌版：保留原作者連結，尊重鳥想安靜的時候，不下載重製歌曲、不承諾每隻鳥都會唱。
